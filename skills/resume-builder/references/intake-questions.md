# Intake and gap-question bank

What to collect at the start (Step 1) and the targeted questions to ask after extraction and research (Step 3). The rule throughout: research and extract first, then ask ONLY what those cannot supply. This is not an interview.

<a name="inputs"></a>
## 1. Inputs to request

- **Old resume (required):** PDF, docx, or pasted text. The factual spine. If none exists, ask the candidate to paste their work history in any form before proceeding.
- **LinkedIn (optional):** invite it with this caveat stated plainly: "A LinkedIn URL will almost certainly be blocked to automated reading (login wall). If you want LinkedIn included, paste the profile text or drop the exported 'Save to PDF' copy (LinkedIn: Me, then More, then Save to PDF)." If only a URL is given, attempt a fetch, and when it is blocked, ask for the export rather than guessing at profile content.
- **Target role / company / job description (optional but high-value):** the posting URL, the company name, or pasted JD text. If absent, ask: "Tailor this to a specific posting (paste it), or build a strong general resume?" Proceed either way.

<a name="gaps"></a>
## 2. Gap questions (ask only the unfilled ones)

After extracting the resume/LinkedIn and researching any target, ask only for what is still missing or ambiguous:

- **Target and level:** what role and seniority is this aimed at? (drives framing and which experience leads)
- **Emphasis:** which 2 or 3 achievements should lead? (the human reads the top of page one first)
- **Missing metrics:** for a bullet that clearly had an outcome but no number, "is there a real figure for this?" If no, keep it qualitative, never invent one.
- **Gaps/dates:** any employment gap or date ambiguity to resolve, and how the candidate wants it handled.
- **Constraints:** any hard requirement in the posting (clearance, location, tool) the candidate meets and should surface.
- **Design flair (only if the target is a design/creative role):** confirm whether they want the designed PDF to carry restrained flair, or stay clean.

<a name="discipline"></a>
## 3. Discipline

- Batch questions (a few at a time), never a wall.
- Never invent a fact, metric, date, or title to fill a gap; flag it and move on.
- Stop once the target, emphasis, and any real gaps are settled. Over-asking is the known failure mode.
